## 📌 About

Preparing for TCS coding rounds often means jumping between different question lists, websites, notes, and progress trackers.

This project brings everything into **one lightweight browser-based DSA preparation workspace**.

It contains questions organized into:

- 🔢 Numbers
- 🧮 Number System
- 📦 Arrays
- ↕️ Sorting
- 🔤 Strings

Questions are arranged progressively by difficulty:

- 🟢 **Easy**
- 🔵 **Medium**
- 🩷 **Hard**

The goal is simple:

> **Learn → Solve → Track → Revise**

---

## ✨ Features

### 📚 Structured Question Bank

The tracker contains **190 unique questions** collected from two TCS-oriented question sets.

Questions are:

- Categorized by topic
- Assigned a difficulty level
- Sequentially numbered
- Linked to their corresponding problem/solution pages

---

### ✅ Progress Tracking

Mark a question as solved using the checkbox.

The dashboard automatically updates:

- Overall progress
- Easy progress
- Medium progress
- Hard progress
- Section-wise progress
- Remaining questions

Your progress is stored locally in your browser.

---

### ⭐ Favorite Questions

Star questions that you want to:

- Revisit later
- Practice again
- Mark as important
- Build a revision list

You can also filter the tracker to show **Favorites only**.

---

### 📝 Notion-Style Notes

Every question has its own personal notes workspace.

The notes editor supports a Notion-like writing experience with:

- Headings
- Paragraphs
- Bold
- Italic
- Underline
- Bulleted lists
- Numbered lists
- Checklists
- Quotes
- Code blocks
- Dividers
- Links
- Slash commands
- Markdown-style shortcuts

Examples:

# Approach

## Idea

- Observation 1
- Observation 2

> Important edge case

```java
// Java solution
```

Notes are stored independently for every question.

---

### 🌙 Dark Mode

A dedicated dark theme is available for comfortable night-time preparation.

The interface includes:

- Dark cards
- Dark question sections
- Improved contrast
- Refined shadows
- Dark editor
- Dark slash-command menu
- Dark form controls

---

### 🔍 Search & Filters

Quickly find problems using:

- Search
- Difficulty
- Section
- Solved / Unsolved
- Favorites

---

### 📂 Collapsible Sections

Each topic is independently collapsible.

Questions are visually indented under their respective section so the structure remains clear even when many questions are visible.

---

## 🗂️ Question Bank

The current question bank is organized into five sections:

| Section | Description |
|---|---|
| 🔢 Numbers | Arithmetic, digit manipulation and mathematical problems |
| 🧮 Number System | Binary, decimal, octal and number representation |
| 📦 Arrays | Array manipulation and array-based problem solving |
| ↕️ Sorting | Sorting, searching and ordering techniques |
| 🔤 Strings | String manipulation, matching and sequence problems |

Questions are organized from:

**Easy → Medium → Hard**

3. Start solving.

That's it.

The application runs entirely in the browser.
